# 🔑 Keyword Extraction (NLP)

## 🧠 Idea
This project extracts the **most relevant keywords** from text using semantic understanding instead of simple frequency counting.

---

## ⚡ How It Works
- Convert text into embeddings using **SentenceTransformer**  
- Compare words/phrases with the main content  
- Use **Cosine Similarity** to find the most relevant keywords  

---

## 🛠️ Stack
- Python  
- SentenceTransformers  
- NumPy  

---

## ▶️ Run

```bash
pip install sentence-transformers
